# 💍 Luxury Cinematic Wedding Invitation Website

A luxury, editorial-grade digital wedding invitation built with semantic HTML5, CSS3, and Vanilla JavaScript. Features full Arabic RTL support, a real-time countdown timer, floating golden sparkle particles on HTML5 Canvas, interactive lightbox gallery, WhatsApp RSVP integration, and full mobile optimization for WhatsApp and social sharing.

---

## 🚀 How to Deploy on GitHub Pages in 2 Minutes

1. **Create a GitHub Repository**:
   - Go to [github.com](https://github.com) and log in.
   - Click the **+** icon in the top right corner and select **New repository**.
   - Name your repository (e.g., `wedding-invitation`).
   - Select **Public**.
   - Click **Create repository**.

2. **Upload the Files**:
   - On the repository page, click **Upload files** (or use git CLI).
   - Drag and drop:
     - `index.html`
     - `style.css`
     - `script.js`
     - `README.md`
   - Click the green button: **Commit changes**.

3. **Enable GitHub Pages**:
   - Click the repository **Settings** tab (gear icon at the top).
   - In the left sidebar, click on **Pages**.
   - Under **Build and deployment** > **Branch**:
     - Change the branch from `None` to `main` (or `master`).
     - Leave the folder set to `/ (root)`.
     - Click **Save**.

4. **Access Your Live Website**:
   - Wait 30–60 seconds for GitHub to build the site.
   - Refresh the **Pages** settings page; a green box will appear showing:
     `Your site is live at https://<your-username>.github.io/wedding-invitation/`
   - Test it directly on mobile and share it via WhatsApp.

## ⚙️ Easy Customization Guide

All personalization settings are managed inside `script.js` in the `WEDDING_CONFIG` object at the top of the file:

```javascript
const WEDDING_CONFIG = {
  groomName: "محمد",
  brideName: "فاطمة",
  weddingDate: "2026-10-09T19:30:00", // ISO format: YYYY-MM-DDTHH:MM:SS
  weddingTimeDisplay: "السابعة والنصف مساءً",
  venueName: "قصر النرجس للأفراح",
  venueAddress: "طريق الملك فهد، حي المروج، الرياض",
  googleMapsUrl: "[https://maps.google.com/?q=24.7136,46.6753](https://maps.google.com/?q=24.7136,46.6753)",
  whatsappNumber: "966501234567", // International format (no + or spaces)
  musicUrl: "URL_TO_YOUR_MP3_FILE",
  groomPhoto: "URL_OR_RELATIVE_PATH",
  bridePhoto: "URL_OR_RELATIVE_PATH"
};
```

### 1. Changing Couple Photos
- **Using local images**: Place your images in an `assets/` folder (e.g., `assets/groom.jpg` and `assets/bride.jpg`) and update `groomPhoto` and `bridePhoto` in `WEDDING_CONFIG`.
- **Using direct links**: Paste direct image links from Imgur, Cloudinary, or AWS S3.

### 2. Changing Background Music
- Place an `.mp3` file in your repository (e.g., `music.mp3`) and set `musicUrl: "music.mp3"` in `script.js`.
- If set to `""`, the site works seamlessly and the floating music button remains inert without throwing errors.

### 3. Updating the WhatsApp RSVP Number
- Change `whatsappNumber` to the phone number designated to receive confirmations (e.g., `9665XXXXXXXX`).
- Customize `whatsappMessage` to change the default message pre-filled when guests click the RSVP button.

### 4. Updating the Google Maps Venue Pin
- Open Google Maps, locate your wedding hall or venue, click **Share**, copy the link, and paste it into `googleMapsUrl`.

## 📱 Features & Highlights
- **Mobile First**: Built to mimic a vertical luxury digital film, designed specifically for WhatsApp webview screens.
- **RTL & Typography**: Utilizes Amiri & Tajawal fonts with precise Arabic letter spacing and alignment.
- **Zero Framework Bloat**: Pure HTML/CSS/JS with zero Node, React, or npm dependencies.
- **Accessibility & Performance**: Uses `prefers-reduced-motion` compliance, GPU-accelerated transforms, and lazy-loaded imagery.
